> **目标**：为前端组件实现与 Stitch 生成的原型提供高保真的业务逻辑、双栏联动规则与交互细节支撑。

## 一、双栏核心联动规则（Left-Right Synchronization）

桌面工作台左右两栏不是孤立的，而是由 **当前选中比赛（`activeMatchId`）** 驱动的强联动体系：

```
用户行为（点击左栏赛程卡片 / 点击 Hero 卡【立即观赛】）
                       │
                       ▼
            更新 activeMatchId 状态
                       │
          ┌────────────┴────────────┐
          ▼                         ▼
   左栏卡片激活高亮            右栏根据比赛状态自动派生呈现：
 (4px 琥珀金边框高光)           ├─ 若当前为【LIVE 进行中】 ──▶ 载入 ArtPlayer 直播流（优先线路1）
                               ├─ 若当前为【即将开赛 / 未赛】 ──▶ 载入赛前战术情报与开球倒计时
                               ├─ 若当前为【已完赛】 ──▶ 载入战报、技术统计与高光集锦入口
                               └─ 若直链提取失败 ──▶ 自动降级为【🛡️ 纯净沙箱内嵌】
```

### 1.1 自动初始化行为
- **首屏打开瞬间**：
  1. 系统运行 `owlDay(now)` 计算今日夜猫口径；
  2. 运行 `pickToday(tonightMatches, preferences)` 选出“今晚之选”；
  3. `activeMatchId` 默认自动锁定为今晚之选的比赛 ID，右栏大屏就绪，**用户无需任何点击，直接看到今晚焦点**。

### 1.2 左栏三大视图切换器（View Switcher Tabs）
左栏顶部设有 `[🌙 今晚] · [📊 本周] · [📅 赛程]` 视图切换，用户切换视图时，**右栏当前播放的比赛绝不中断**：
- **切到【🌙 今晚 (Tonight)】**：左栏聚焦于当晚 3~6 场比赛与今晚之选 Hero 卡，心智为“立刻看球”；
- **切到【📊 本周 (Week)】**：左栏切换为 0-1 背包 DP 规划器、推荐组合与本周焦点战，心智为“熬夜算账”；
- **切到【📅 赛程 (Schedule)】**：左栏释放全部纵深，用于虚拟滚动全季 1,897 场大日历检索。
切换 Tab 仅改变左栏呈现，右栏大屏播放状态（码率、时间轴、全屏状态）100% 保持不动。

## 二、线路切换台（Stream Switcher）状态机

右栏播放器下方的线路切换台控制着用户的观赛通道：

| 线路类型 | 来源标识 | 渲染容器 | 异常处理机制 |
| :--- | :--- | :--- | :--- |
| **线路 1 (默认主选)** | 咪咕原画 / 官方直链 | `ArtPlayer` + `hls.js` | 连续缓冲超过 3 次或 403 $\rightarrow$ 自动触发切线吐司提示，切换到线路 2 |
| **线路 2 (官方高清)** | 腾讯 / 央视 / 官方超清 | `ArtPlayer` + `hls.js` | 同上 |
| **线路 3 (原声备用)** | 英文原声 / SkySports | `ArtPlayer` + `hls.js` | 支持保留当前音量偏好 |
| **线路 4 (沙箱内嵌)** | 聚合站内嵌播放页 | Electron `<webview>` / 沙箱 iframe | 启动广告网络拦截 + 元素隐藏，屏蔽全屏弹窗 |
| **↗ 直达原站** | 官方/源站原网页 | 系统默认浏览器打开 | 在外部浏览器新窗口弹出，附带对阵关键词 |

## 三、桌面极客快捷键体系（Desktop Hotkeys）

为了给桌面硬核球迷最顺滑的体验，播放器与工作台绑定全局与局部快捷键：

| 快捷键 | 作用 | 作用域 | 交互反馈 |
| :--- | :--- | :--- | :--- |
| `Space` | 播放 / 暂停 | 全局（非输入框聚焦时） | 播放器中心微缩显示播放/暂停动画 |
| `F` | 全屏 / 退出全屏 | 播放器 / 全局 | 播放大屏沉浸全屏显示，再按退出 |
| `P` | 画中画（Picture-in-Picture） | 播放器 | 视频脱离浏览器浮动在桌面角落 |
| `M` | 一键静音 / 取消静音 | 播放器 | 屏幕显示静音图标，深夜防打扰 |
| `1 ~ 4` | 秒级切换线路 1 至 4 | 播放器聚焦时 | 线路按钮高亮瞬间切换，保留当前播放时间轴 |
| `↑ / ↓` | 音量调节（步进 5%） | 播放器 | 右下角显示音量胶囊进度条 |
| `Esc` | 关闭偏好设置抽屉 / 退出全屏 | 全局 | 恢复主工作台 |

## 四、防剧透模式（Spoiler-Free Mode）交互细节

在设置中开启「防剧透模式」（默认建议开启）：
1. **已赛场次（`st === 'done'`）表现**：
   - 赛程列表中，比分区域呈现模糊毛玻璃暗色药丸：`[ 👁️ 点击揭晓 ]`；
   - 鼠标悬停时，提示文案变为 `[ 2 - 1 ]`；
   - 单击一次后，该场比赛永久揭晓比分；
2. **正在进行场次（`st === 'live'`）**：
   - 不受防剧透影响，实时显示当前动态比分与比赛时间（如 `68'`）。

## 五、左栏空间优化：睡眠预算卡的手风琴折叠状态机

为保证 1440×900 屏幕下赛程列表能拥有最大纵向展示空间，本周睡眠预算规划卡设计为 **双模态折叠（Accordion）**：

1. **紧凑常态（Compact Mode - 默认）**：
   - 高度仅 `36px`，以单行胶囊形式呈现：
     `[🌙 本周预算: 4.0h · 已选 3 场建议 3.5h (87%)]   [展开规划 ▾]`
   - 释放出约 `80px` 垂直高度给赛程列表，让赛程列表可多显示 1~2 场比赛；
2. **展开编辑态（Expanded Mode）**：
   - 点击右侧 `[展开规划 ▾]`，顺滑展开为带滑动条的交互面板（高度 `115px`）；
   - 用户拖动预算条（如从 4.0h 改为 2.5h），DP 背包算法即时复算，赛程列表中被背包选中的卡片高亮金边闪烁，未入选场次降低对比度。

## 六、设计细节排定结果（2026-09-12 已确认）

> 原「待沟通确认的 4 个细节」已全部排定，依据《决策排定与开工执行清单》。

1. **关注球队 / 关注联赛入口形式** → **设置抽屉内多选**
   - 点击顶栏 `[⚙ 偏好设置]` 滑出抽屉，在抽屉内做**七大联赛**（含 SCG）多选。
   - ⚠️ **必须与列表筛选药丸严格区分**：关注联赛是**算法偏好输入**（影响 +8 加成，仅已选 < 6 个时生效）；列表筛选只过滤显示，不影响算法。二者绝不可混排。
2. **无球日（如国际比赛日周）右栏呈现** → **倒计时表盘**
   - 右栏显示开球倒计时大表盘 + 下一场焦点战对阵巡礼。
   - ⚠️ **不得出现**"战术板球场透视""阵型图"等元素（无球员/阵型数据，见 UI 规范 §五）。
3. **播放器自动静音策略** → **首次起播默认静音**
   - 现代桌面浏览器对 autoplay 有限制，须首帧静音。
   - 画面中央轻量提示 `[ 🔊 点击开启声音 ]`；用户手动开启后，后续线路切换**保留音量偏好**（PRD FR-P-11）。
4. **队徽呈现尺寸** → **28px / 36px**
   - 紧凑赛程列表 `28px × 28px`，今晚之选 Hero 卡 `36px × 36px`。
   - 素材用**本地 111 张 PNG**（`miniprogram/images/crests/`），不用三字码圆标；⚠️ 勿取顶层 `images/crests/` 的 96 张旧版残留。

## 七、Hero 卡分档状态（2026-09-12 新增）

依据 PRD §7.5.4，Hero 卡按夜猫指数分三档，**视觉必须可区分**：

| 档位 | 触发 | 占全年有赛夜 | 表现要点 |
| :--- | :--- | ---: | :--- |
| **高光卡** | 指数 ≥ 15 | 40%（34 晚） | 完整态：「今晚唯一焦点」徽章 + ROI + 看点叙事 + 主 CTA |
| **标准卡** | 5 ≤ 指数 < 15 | 27%（23 晚） | 去「唯一焦点」措辞，保留对阵 / 档位 / CTA，ROI 弱化 |
| **弱化卡** | 指数 < 5 | 33%（28 晚） | 「今夜无必看」+ 可看场次列表；不吹、不硬推 |
| **无球日**（独立态） | `pickToday() → null` | 全年 131 晚中 46 晚 | 下一场焦点战倒计时大表盘 |

> 设计稿目前**只产出了「高光卡」一态**。标准卡 / 弱化卡 / 无球日三态**需补视觉稿**。
